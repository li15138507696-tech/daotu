# 道途 1.8.4 通用版

适用 Minecraft 1.21.1 / NeoForge 21.1.232 及以上；本体为可选依赖，不读取本体内部类或字段。本版采用独立成长：击杀、移动、探索新群系和在线时间获得历练，潜行静止且站在地面时修炼速度翻倍。历练满后使用 `/daotu` 打开界面选属性，键位默认未绑定，可在控制设置中自行绑定。界面只在主动打开且未占用其他界面时显示。

道途属性由 `daotu` 命名空间的临时属性修正实现；试炼和旧历史仍保存。每十抽也提供独立属性选项；道痕、流派熟练度、气运、本体增益和纪事采样等旧本体联动暂停，不再提供新奖励。旧版待选奖励中的本体联动项备份在 `daotu/universalLegacyOffer`，安全属性项保留，旧历练不扣除。旧本体增益数据保留但通用版不再应用。纪事数据保留并可查看，但不新增本体采样。

通用版无法安全判断本体转世，不会因为普通死亡或本体流程自动清除道途成长；转世后独立成长继续保留。旧版曾写入本体的道痕、流派、身份等字段不会自动撤销：无法安全区分其来源或其他模组的修改。存档转换前建议自行备份世界。

服务端和客户端都需要安装同一通用版（网络协议 6）。静态编译和离线夹具测试不能证明实际游戏中的兼容性或数值平衡。

1.8.4 会备份并过滤无效、无法应用或已封顶的旧候选；有效候选保留原序。旧出身或阶位未折算时，在待选领取后按原规则补足独立属性抽次，已有抽次计入额度，历练池及原始旧字段保留；无法确认来源的已有属性不会重复补发。
